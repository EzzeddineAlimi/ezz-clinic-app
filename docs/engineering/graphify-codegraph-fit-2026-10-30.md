## One bounded evaluation path — opt-in, not executed

The official project on PyPI is **graphifyy** (double y), Python >=3.10. Its SQL grammar is an **optional [sql] dependency**; without it, SQL relationship coverage may degrade or vanish. Upstream source at v0.9.99 was observed, but only the **0.9.98 PyPI distribution** was independently confirmed published on 2026-10-30 ([PyPI release](https://pypi.org/project/graphifyy/0.9.98/)). The v0.9.98 source tag was separately checked to support --code-only and --out. The commands below are an **unrun, developer-only test procedure**, not a claim of installation or an approved default dependency.

From a fresh local checkout containing **only source and fictional test data**, after inspecting local files for unexpected secrets:

    graphout="$(mktemp -d)"
    GRAPHIFY_BACKEND=none uvx --from 'graphifyy[sql]==0.9.98' graphify extract . --code-only --out "$graphout"
    GRAPHIFY_BACKEND=none uvx --from 'graphifyy[sql]==0.9.98' graphify affected 'backend/src/modules/billing.ts' --graph "$graphout/graphify-out/graph.json"

Prerequisites: Python 3.10+, uv/uvx, package download access, a clean disposable checkout. The first command downloads third-party Python dependencies, so it needs a normal supply-chain review before a developer or runner executes it. We **have not executed or validated this package on EZZ** (the available analysis runtime had no GitHub network access). Commands deliberately omit --postgres, --backend, --no-gitignore, --watch, --mcp, --global, --dedup-llm and all cloud/hosted features. Output is in a temporary folder outside the repository; do not upload graph JSON, HTML, caches or raw corpus to GitHub, Mission Control or a third-party service. The repo's .gitignore also excludes graphify-out/ to prevent accidental local default-path commits. A clean process should have no provider credentials exposed to the scanner.

## No changes to EZZ's authority structure

- EZZ remains a modular TypeScript/React/PostgreSQL monolith with its existing 61 V1 acceptance groups and exact-head CI/Playwright/PG16 evidence.
- GitHub issues/PRs plus Mission Control remain the task and review system. Graphify is an **optional, read-only map**, never an editor, code reviewer, paid external agent, clinical knowledge base, FHIR replacement, new database or production dependency.
- Independent Primary Muse safety and Muse Ons UX review, founder high-risk merge authorization, issue #68 branch protection, issue #72 production security and real patient-data prohibition remain unchanged.
- Stop this pilot if any unexpected network activity, unknown data export, secret exposure, false authority claim, tooling incompatibility, excessive overhead or stale-graph misclassification is observed. Remove generated outputs locally; no evidence uploaded by default.

**Result of this PR:** an explicit safe evaluation contract and a generated-artifact ignore rule. **NOT_DONE:** package execution, measured EZZ graph quality, cost/time savings, CI integration, independently reviewed adoption, production deployment.
